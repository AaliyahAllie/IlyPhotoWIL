# ILY Photo Frontend Prototype (ASP.NET Core MVC)

## Open in Visual Studio
1. Extract the zip.
2. Open `IlyPhotoFrontend.csproj` in Visual Studio 2022.
3. Allow NuGet/.NET restore if prompted.
4. Press `Ctrl + F5` or the green Run button.

## Demo logins
- Admin: `admin@ilyphoto.co.za` + any password
- Client: any other email + any password

## Important
This is a frontend/UI prototype with demo session routing and mock data only. It does not use a database, real authentication, email delivery, cloud photo storage, secure invoice generation, or permanent booking storage. Those must be added in the backend phase.
